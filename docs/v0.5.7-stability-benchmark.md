# GeoChat 0.5.7 稳定性与 Benchmark 方案

## 目标

0.5.7 将“能运行”提升为“可重复验证、可定位失败、可比较回归”。本版本同时交付：

- 版本化 Benchmark 题库，公开任务与私有评分标准严格分离；
- 可确定重放的离线评分器与结果持久化；
- 复用原生 AI SDK、Renderer 工具续接和真实 GeoGebra 画板的桌面业务测试入口；
- 网络、题库缓存、Agent ledger 与 GeoGebra 工具链的 CI 门禁；
- 失败证据默认脱敏，不记录 API Key、Authorization 或完整大体积附件。

## 不变量

1. Benchmark 不创建第二套 Agent loop，候选运行复用生产 `ToolLoopAgent` 与 Renderer 工具续接。
2. 模型只接收公开任务投影；答案、解析、oracle、reference command 和评分阈值不得进入提示词、工具参数或公开题目 API。
3. Benchmark 固定 `suiteId + version + manifest hash + case revision`，运行开始后不跟随远端 latest 漂移。
4. 离线回归只证明机制确定性；真实模型评测单独报告，不能用 mock 全绿代表模型能力。
5. 自动评分读取冻结后的证据，且发生在候选运行结束之后。
6. 真实桌面评测使用隔离的用户数据目录、SQLite、对话和画板；运行器会拒绝重置普通用户画板。

## 首批范围

首批 `core-v1` 包含 12 个原创 smoke case，覆盖二维构造、函数、依赖对象与三维/多视图。每个 case 包含：

- `task`: 仅含模型可见的标题、题面、能力、标签和媒体引用；
- `oracle`: 声明式 assertions，不执行任意 JavaScript；

评分器测试为套件中的每一道题生成正确与错误观测，证明 grader 同时能接受正确结果和拒绝错误结果。

首版 grader 支持答案字符串/选项、数值容差、对象数量与类型、工具契约及人工复核占位；未评项不自动记为通过，并报告自动评分覆盖率。

## 状态机

```text
queued -> preparing -> ready -> running -> collecting -> grading
       -> awaiting-review -> completed
```

旁路终态：`failed`、`cancelled`、`interrupted`、`unsupported`。Agent run 的 `succeeded` 仅表示业务链路结束，不等同于题目通过。

## 验证分层

- PR：TypeScript typecheck、Bun tests、Rust tests、Benchmark schema/hash/泄漏/评分正反例、Renderer build。
- 本地：隔离 Tauri dev/packaged app 的真实 MCP action queue、真实 GeoGebra 工具和 ledger 终态。
- 手动/定时：固定 suite 的真实供应商模型评测，记录环境快照、重复次数、耗时与 token 波动。

## 0.5.7 发布门槛

- 12/12 Benchmark case 通过 schema、hash 与 grader 正反例验证；
- Benchmark 结果可创建、持久化、查询、取消/中断并导出结构化证据；
- Bun、TypeScript、Rust、Renderer build 与打包 smoke 全绿；
- 桌面调试动作不会把回报失败误报为成功，公开 MCP 能力与 Renderer 实际能力一致；
- 版本、GitHub Release、R2 latest 与官网链接均更新到 0.5.7。

## 运行真实桌面 Benchmark

只对当前仓库启动的隔离测试实例运行，不能连接已安装的日常使用版本：

```bash
GEOCHAT_DESKTOP_USER_DATA_DIR="$PWD/.artifacts/benchmark-profile" \
GEOCHAT_DESKTOP_MCP_DB_PATH="$PWD/.artifacts/benchmark-profile/geochat-benchmark.sqlite" \
GEOCHAT_DESKTOP_LOCAL_AUTH_TOKEN=benchmark-local \
bun run tauri:dev:mcp

# 在隔离实例内配置测试模型后，使用实际启动日志中的动态端口：
GEOCHAT_DESKTOP_MCP_URL=http://127.0.0.1:<mcp-port>/mcp \
GEOCHAT_DESKTOP_BACKEND_URL=http://127.0.0.1:<backend-port> \
GEOCHAT_DESKTOP_LOCAL_AUTH_TOKEN=benchmark-local \
bun run benchmark:run
```

运行器逐题重置隔离画板、走真实桌面消息与 AI SDK 工具链、冻结 Agent run/画板证据、离线评分，并将报告写入 `.artifacts/benchmarks/latest.json`。未识别为 benchmark 的数据库默认拒绝运行；只有明确可丢弃的测试配置才能通过 `GEOCHAT_BENCHMARK_ALLOW_CANVAS_RESET=1` 覆盖。
