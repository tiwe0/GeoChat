# Homepage plugin extension

Mode: Persuade. Audience: existing DeepSeek Harness users looking for a mathematical canvas. Approved scope: preserve the desktop homepage and add a plugin section immediately after the hero, with a real screenshot, installation and limitations in both languages.

## Direction contract

THESIS: show GeoChat operating inside Harness, not a second desktop download promotion.

OWN-WORLD: inherit the website's paper, ink, construction-blue, Archivo, drafting rules and restrained controls. No global token or identity changes.

STORY: understand the native integration, see the actual canvas, install a versioned package, and understand the memory and license boundaries.

FIRST VIEWPORT: preserve the existing hero. The following section opens with the plugin title and install action; a full-width screenshot precedes a two-column capability/installation block, stacked on mobile. The only interaction added is copying the real install command with accessible success/failure feedback. No new decorative animation.

FORM: local extension of the established surface, user-approved; no concept seed or generated comp.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Proof: `docs/media/geochat-dsh-plugin.png`, the user-selected Harness screenshot; plugin README and published v0.1.5 release. WebP derivatives retain the full image without changing content. Design-system files remain unchanged.
